# Скриншоты Lofi Girl

Flask-приложение "Скриншоты Lofi Girl" - галерея скриншотов с атмосферой lofi. Проект является продолжением приложения, созданного на занятии, предметная область сохранена.

## Возможности

- главная страница со списком скриншотов: превью, название, настроение и описание;
- страница подробностей со скриншотом в полном размере;
- добавление нового скриншота с серверной валидацией;
- редактирование существующих скриншотов;
- удаление скриншотов через POST;
- поиск по названию;
- фильтрация по настроению.

## Реализованные дополнительные функции

Из списка домашнего задания выбраны три функции, которые подходят для галереи скриншотов:

1. **Поиск.** На главной странице есть поле поиска. Запрос передается через `request.args` (`GET /?q=...`), поиск идет по названию без учета регистра. Пример: `/?q=winter` находит скриншот "A Winter's Love".
2. **Фильтрация.** Рядом с поиском есть выпадающий список настроений. Значение передается через `request.args` (`GET /?mood=...`), показываются только записи с выбранным настроением. Пример: `/?mood=учёба` оставляет только "Submerge".
3. **Удаление.** На странице подробностей есть кнопка "Удалить скриншот". Она отправляет POST на `/screenshots/<id>/delete`. После удаления выполняется `redirect()` на главную страницу.

Поиск и фильтрация работают вместе: можно указать оба параметра одновременно.

## Редактирование

На странице подробностей есть ссылка "Редактировать". Она открывает форму `/screenshots/<id>/edit`, заполненную текущими значениями объекта. После отправки POST сервер проверяет поля через `request.form`:

- название и описание обязательны;
- выбранное изображение должно существовать в `static/images`;
- при ошибках форма возвращается с сообщениями и ранее введенными значениями;
- при успехе объект обновляется в списке, затем выполняется `redirect()` на страницу объекта.

## Маршруты

| Метод | URL | Назначение |
| --- | --- | --- |
| GET | `/` | главная страница, список скриншотов, поиск и фильтрация |
| GET | `/?q=...&mood=...` | поиск по названию и фильтрация по настроению |
| GET | `/screenshots/<id>` | страница подробностей |
| GET, POST | `/screenshots/add` | форма добавления и добавление объекта |
| GET, POST | `/screenshots/<id>/edit` | форма редактирования и сохранение изменений |
| POST | `/screenshots/<id>/delete` | удаление объекта |

## Запуск

Установить Flask, если он еще не установлен:

```
py -m pip install flask
```

Запустить приложение:

```
py app.py
```

Открыть в браузере: http://127.0.0.1:5000

## Шаблоны

Все страницы наследуют `base.html` через `extends` и переопределяют блоки `title` и `content`. Формы добавления и редактирования используют общий шаблон `_form.html`, чтобы не дублировать HTML. Ссылки строятся через `url_for()`, данные выводятся через Jinja (`{{ }}`, `for`, `if`).

## Примечание

База данных не используется. Объекты хранятся в списке словарей в памяти процесса, поэтому после перезапуска приложения изменения сбрасываются к начальным трем записям.
